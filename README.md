# DueloGenerala
Cada jugador tiene 13 turnos, uno por cada casilla de su planilla, y se alternan. En tu turno tiras 5 dados hasta 3 veces, y tras cada tirada puedes guardar los que te sirven y volver a tirar el resto. Luego anotas el resultado en una casilla libre. Si no cumples la combinación, anotas 0 en ella, así que cada decisión cuesta algo.
